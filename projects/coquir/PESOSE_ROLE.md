# PESOSE role

Core prior artifact for the revised security-only scope. The relevant benchmark tasks are `SaferCodePreferenceRetrieval` and `CVEFixesPreferenceRetrieval`. Other quality dimensions remain for paper-artifact completeness but are not proposed PESOSE deliverables.

Running the security subset needs the retrieval models and datasets named in `README.md` and `src/evaluate_coquir.sh`; neither is vendored here, so this artifact is not exercised by PARAPET's automated tests.
